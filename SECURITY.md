# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities **privately**. Do not open a public
issue for a security problem.

Use GitHub's private vulnerability reporting on this repository
(Security tab -> "Report a vulnerability"), or email
**bhatiaansh716@gmail.com**.

Include:

- A description of the issue and its impact
- Steps to reproduce
- Affected version(s) and environment
- Any suggested fix or mitigation

## What to expect

- Acknowledgement of your report as soon as possible
- An assessment and, where confirmed, a fix and coordinated disclosure
- Credit in the release notes if you wish

## Scope

This policy covers the source code and configuration in this repository. It does
not cover third-party dependencies, which should be reported to their own
maintainers.

## Supported versions

Security fixes are applied to the latest released version.
